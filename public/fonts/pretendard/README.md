# Pretendard

이 폴더의 글꼴 파일은 [Pretendard](https://github.com/orioncactus/pretendard)를
그대로 재배포한 것입니다. 자체 호스팅하는 이유는 **외부 요청을 만들지 않기 위해서**입니다
(`.dev/DESIGN.md` §2, 폐쇄망 배포 [F-23]).

라이선스는 [`OFL.txt`](./OFL.txt)에 있습니다 — SIL Open Font License 1.1.
**이 파일을 지우거나 글꼴만 따로 옮기지 마세요.** OFL 1.1은 글꼴을 재배포할 때
라이선스 전문을 함께 두도록 요구합니다.

`OFL.txt`는 Pretendard 저장소의 `LICENSE`를 바이트 그대로 가져온 것입니다.
Pretendard 외에 Source(Adobe) · Inter · M PLUS 1의 저작권 표시가 함께 들어 있습니다 —
Pretendard가 그 글꼴들을 바탕으로 만들어졌기 때문입니다.
